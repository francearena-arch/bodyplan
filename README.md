# BodyPlan

Mobile-first, offlinefähige Fitness-PWA.

## Installation
Den Inhalt dieses Releases in das bestehende GitHub-Pages-Repository hochladen. Gleichnamige Dateien ersetzen. Die Ordnerstruktur beibehalten.

## Daten
Trainingsdaten werden lokal im Browser gespeichert. Vor Updates ein Backup über Einstellungen erstellen. Browserdaten nicht löschen. Dieses Release migriert bestehende Daten nicht destruktiv und behält gespeicherte Trainings beim Löschen eines Plans.

## Heatmap
Die anatomischen Originalbilder und die pixelgenau darauf registrierten Masken gehören zusammen. Die Masken sind keine frei positionierten CSS-Overlays. Reizpunkte sind gewichtete Arbeitssätze, keine medizinische Messung von Muskelwachstum oder Regeneration.
